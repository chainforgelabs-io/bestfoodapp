# Frontend (Best Food App)

React (Create React App) client for Best Food App.

See the [root README](../README.md) for stack, environment variables, and how to run the monorepo.

```bash
# From repo root (recommended)
npm run dev

# Or frontend only (API must already be running)
cd frontend && npm start
```
